# Spotify Music Data Analysis 🎵

### Python Fundamentals Challenge – CIE 1

## About the Project

This project is about exploring Spotify music data using Python. I have used Pandas and NumPy for data cleaning and analysis, and Matplotlib and Seaborn for visualizing the results.

The analysis focuses on different song attributes like popularity, danceability, energy, loudness and duration.

## Dataset

Spotify Tracks Dataset (CSV format).

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

## What I Did

- Loaded and explored the dataset.
- Cleaned and transformed the data.
- Identified and handled missing values using mean imputation wherever applicable.
- Explored different music attributes.
- Generated insights and visualized the results.
